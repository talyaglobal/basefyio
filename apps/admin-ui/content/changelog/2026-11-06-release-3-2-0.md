## What's new

- Storage: the bucket switch is now labelled "Public bucket" (on means public), and making a bucket public asks for confirmation first. The switch and the delete-bucket icon have accessible names.
- Storage: the bucket Settings tab shows the current object count and size after uploads and deletes, without a page refresh.
- Storage: when a new bucket name contains capitals, spaces or other characters, the form says how it will be created instead of changing it silently.
- Connect: when no separate direct Postgres endpoint exists, the page no longer presents the pooler address as a "direct" connection. It explains that connections run through the pooler in transaction mode and what that rules out.
- Connect: added Drizzle, TypeORM and SQLAlchemy examples next to Prisma, and the Raw Editor text no longer promises editing (it copies).
