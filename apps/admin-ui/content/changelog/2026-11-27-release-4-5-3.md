## What's new

- New e-mail provider **tsmartsend** in project settings > Auth > Email. A project's verification, reset, magic-link and invite mails are sent through your own tsmartsend project: pick the provider, paste its API key (`ts_…`) and set a sender address on a domain verified there. The settings page links to tsmartsend if you still need to create a project.
- The API key is stored encrypted and is never shown again; the page only displays "saved".
- Self-hosting: platform mail can be switched to tsmartsend by name with `MAIL_TRANSPORT=tsmartsend` and `TSMART_SEND_API_KEY`. Nothing changes unless you set it.
