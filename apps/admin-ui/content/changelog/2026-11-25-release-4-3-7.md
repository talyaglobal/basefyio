## What's new

- **Documentation sorted by topic.** If you self-host basefyio or read the docs in the repository, seven pages moved into the folder where they belong: API tokens and realtime into `docs/reference/`, the Codefyio adapter into `docs/integrations/`, point-in-time recovery and off-site backups into `docs/ops/`, and both self-hosting guides (English and Turkish) into `docs/guides/`. The README, the docs index and every cross-link point to the new places. If you linked to one of these pages directly, use the new address, for example `docs/guides/self-hosting-offline.md`.
