## What's new

- Uploading a 0-byte file (dashboard, `POST objects`, Storage API) now stores an empty object instead of answering `500` (feedback #258).
- Uploading several files from the dashboard no longer stops at the first failure: every file is attempted and a summary lists which ones failed (feedback #259).
- `objects/move` refuses to overwrite an existing destination (`409`) and answers `404` for a missing source or folder; the whole batch is checked first, so nothing is moved on a refusal (feedback #260).
