## What's new

- Billing: choosing Upgrade on a team without a card on file opens the card form first and continues to the upgrade confirmation as soon as the card is saved. The confirmation no longer says your card will be charged when there is none.
- Billing: the Current costs total is now the sum of the amounts shown on the project rows, so cents no longer drift by one.
- Billing: Project costs can be sorted by cost so far, projected cost or name.
- Billing: when the Usage card counts more API requests or traffic than the project rows, a note under the table says how much is not listed there (account-level calls and deactivated or deleted projects).
- Account: sign-in emails are now one choice (never, new device or browser only, every sign-in) instead of two switches that could contradict each other.
- Account: browser notifications have their own card, and the permission shows as Allowed, Blocked or Not asked yet instead of the raw browser value.
- Account: accounts that sign in with Google or GitHub get a readable notice (better contrast, correct names) and a Sign-in and security note explaining that the password and two-step verification live with the provider.
