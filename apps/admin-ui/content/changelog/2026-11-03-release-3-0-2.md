## Fixes

- **Revoking an API token is final.** "Roll secret" on a revoked token gave it a new secret and made it active again; rolling and editing a revoked token are now refused. Revoked tokens can be removed from the list, and the list shows when each token expires.
- **Public buckets share files, not a listing.** Anyone with a file's URL can still read it, but the bucket's address no longer lists every file in it. Existing public buckets were updated automatically.
- **Uploaded pages are downloads.** HTML, SVG, XML and JavaScript files uploaded to storage are served as downloads instead of being opened in the browser, so a file cannot run as a page on the shared storage address. Images, videos and PDFs open as before.
- Public links to files whose names contain `#`, `?` or spaces now work.
