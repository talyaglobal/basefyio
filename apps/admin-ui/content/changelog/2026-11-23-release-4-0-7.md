## What's new

- **Schedule a flow.** A Schedule trigger now has a cron field (UTC) with ready-made examples. The flow card shows the expression and the next run.
- **Call a flow from outside.** A Webhook flow shows its URL and how to sign a call, with a curl example. Its secret is shown once when you save the flow or rotate the secret.
- **Edit flows.** Change a flow's name, trigger and actions after creating it. Switching an action's type starts it blank, so an old log message no longer ends up on an HTTP request. The chosen HTTP method is saved, with POST as the default. Mistakes are shown next to the field.
- **See how a run ended.** Run waits for the result and says whether the run succeeded or failed, and why. Each run opens to show every action's outcome, HTTP status included.
- **Embedding API keys are checked before they are saved.** A key is tried with one small request first. A key the provider rejects is refused with its reason and not stored. The key card names the provider the key is used with. Semantic search answers `200`.
- Turning a webhook flow on or off no longer returns its secret.
