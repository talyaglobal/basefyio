## What's new

- SQL editor: `select count(*), count(*) filter (where …)` returns two columns, `count` and `count_1`, instead of letting the second overwrite the first.
- Overview: the "Last import" card shows the time of the latest import from Supabase, a project ZIP or Data > Import Data.
- AI panel: no more `"undefined"` project name while the project is loading.
