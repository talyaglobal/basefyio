## What's new

- Projects on a phone: a Folders button opens the folder, tag, Trash and Deactivated panel, the toolbar wraps so New Project is always reachable, and the page no longer scrolls sideways.
- The phone menu now lists Billing, API Tokens, Sheet to App and Feedbacks, shows the real team selection (including All Teams) and lets you switch teams.
- Dialogs taller than the screen, such as New Project, scroll inside it, so the title and the close button stay visible.
- Project cards fill the space that is really free beside the sidebar and the AI panel, and the sizes no longer wrap.
- The AI panel starts closed on screens narrower than 1440 px unless you opened it before; your choice is remembered.
- In the Auth user and session tables the Actions column stays visible while the table scrolls sideways.
