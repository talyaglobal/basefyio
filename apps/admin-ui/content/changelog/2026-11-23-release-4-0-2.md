## What's new

- **Document collection endpoints report bad input clearly.** A malformed `filter`, `sort` or `project` query parameter answers `400` naming the parameter, a document id that is not a valid UUID answers `404` instead of a database error message, dropping a collection that does not exist answers `404`, and creating an index without a field path answers `400`.
- **The audit log table names its time zone.** The Time column header shows the time zone the times are displayed in (your browser's).
- **Old Feedbacks page links no longer end in a 404.** A feedback whose stored page was the removed `/dashboard/management` now opens the dashboard.
