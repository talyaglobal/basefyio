## What's new

- An embedded select such as `from('users').select('id, applications(id)')` works again when `applications` also has foreign keys to `auth.users`. Only foreign keys between your `public` tables count as relationships, as on PostgREST, so those extra keys no longer make the embed ambiguous. Hints such as `users!conversations_user1_id_fkey(id)` still work.
- `supabase.rpc()` on a function declared `RETURNS TABLE(role text)` returns `[{"role":"user"}]`. It returned `[null]` for a table with a single column. Functions with several columns, `RETURNS SETOF text` (an array of values) and `RETURNS text` (one value) are unchanged.
