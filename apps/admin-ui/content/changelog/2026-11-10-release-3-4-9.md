## What's new

- Sheet to App: after "Sync from Excel" the "Schema migrations" panel stays visible and "Plan changes" lists the new or changed columns. Generate no longer treats tables that already exist as up to date, so a new column (for example `phone`) is added by applying the planned migration.
- Generate can import the rows of your file into the new tables: tick "Import the rows too" and choose the file. Rows that do not fit a column type are skipped and counted.
- Columns such as `orders.customer_id` that match another table (`customers.customer_id`) get a UNIQUE key on the target and a foreign key; the detected links are listed in the data model. If your data does not satisfy a link, it is skipped with a note and the tables stay.
- After generating, a note tells you that row-level security is on and only the service key has a policy: add policies before reading the tables with the anon or user key.
