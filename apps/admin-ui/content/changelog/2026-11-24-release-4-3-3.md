## What's new

- **Search in a folder.** The Storage file browser has a search box that filters the open folder by name, as you type.
- **Sort files.** Sort by name, size or last modified, ascending or descending. Folders stay on top, by name.
- **Links that open a bucket or folder.** The address now shows the bucket and folder you are in, so you can share the link, bookmark it, and use the browser's back button to go up a step.
- **Realtime asks first.** **Select all** and **Clear all** on the Realtime page now confirm before changing every table and collection, and say how many they will change. **Select all** reminds you that events carry full row data and can be read with any project key. The page also shows how many are enabled.

Still to come in Storage: previews, a grid view, and per-bucket size and file type limits.
