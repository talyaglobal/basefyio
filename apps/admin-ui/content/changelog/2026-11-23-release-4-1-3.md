## What's new

- **Export project logs.** Export CSV on the Logs page downloads the events that match your current search and filters, newest first, up to 5,000.
- **SQL scripts are logged in full.** A script with several statements is logged with its statement count and the rows of all of them, not only the last one's.
- **The point-in-time recovery window loads quickly.** It used to list every archived WAL file on each visit, which took seconds. The summary is now shared and refreshed every minute.
- **The Backup & Export page refreshes less.** It reloads its backup data when a backup or export changes, not on every edit to the project.
