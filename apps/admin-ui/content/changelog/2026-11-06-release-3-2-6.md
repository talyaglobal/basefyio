## What's fixed

- Adding a card no longer fails with an internal error for teams whose billing profile referred to a customer Stripe no longer has. The profile is repaired automatically the next time you add a card or start a checkout.

## Behind the scenes

- The card path (payment account, webhook and the card form's key pairing) is now tested every ten minutes, and an operator alert is raised if it stops working.
