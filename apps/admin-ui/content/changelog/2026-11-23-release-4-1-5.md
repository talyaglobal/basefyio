## What's new

- **Signed upload URLs in basefyio-js.** `createSignedUploadUrl(path, { upsert })` returns a URL and token that let someone without a key upload that one object for two hours. `uploadToSignedUrl(path, token, file)` performs the upload. The upload still counts against your plan's storage and follows the bucket's rules. It does not overwrite an existing object unless `upsert` is set.
- **Documented.** The storage reference now describes signed uploads: `POST /api/storage/v1/object/upload/sign/:bucket/:path` to get the URL, and a `PUT` to use it.
