## What's new

- **The database server no longer runs out of connection slots.** The connection pooler used to keep five connections open for every project database, even when nobody was using it. Together they took about nine in ten of the server's connections, so an import, the SQL editor or an MCP query could be refused with "remaining connection slots are reserved". An idle database now gives its connections back after ten minutes and takes one again on its next query, so the first query after a quiet spell can take a few milliseconds longer.
- Self-hosted installs can still keep connections warm by setting `PGBOUNCER_MIN_POOL_SIZE` above zero.
