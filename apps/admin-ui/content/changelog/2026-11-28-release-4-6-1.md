## What's new

- **Vectors computed from your records.** Set an entity to platform mode and name the text fields to use (`sourcePaths`). basefyio computes the vector for each record in the background when it is created or changed, and stores it alongside the record in the document store. Records whose text did not change are not computed again.
- **Search with plain text.** `POST /api/v1/projects/{id}/data/{entity}/search` now accepts `query` (text) as well as `vector`. Text search is available on platform-mode entities; entities that hold vectors you computed yourself keep searching by vector.
- **Re-embed and status.** `POST .../entities/{entity}/reembed` recomputes an entity's vectors, for example after you change the embedding model, and `GET .../vector-status` shows how many records are embedded, pending or failed.
- **Vectors panel in the dashboard and in the SDK.** Each Data Engine entity has a Vectors panel to turn the feature on, pick source fields, follow progress and try a search. The JavaScript SDK (2.8.0) adds `search`, `setVector`, `getVector`, `deleteVector`, `vectorConfig`, `vectorStatus` and `reembed`.
- **Plans and limits for embeddings.** Computing embeddings with the platform's key, on the embeddings API and in the Data Engine, is included from the Pro plan (Legacy teams included), up to 1,000,000 tokens per project per day. On the Free plan you can add your own embedding provider key in the project's AI settings, which is not limited on any plan, or store vectors you computed yourself. Status responses show whether the platform key is available and how much of the daily limit is used.
