## What's new

- Console, Users & billing: the user list and plan data load once instead of twice, switching tabs no longer blanks the whole screen after the first visit, and the open tab is kept in the address (`?tab=`), so a reload or a shared link lands on the same tab. The SEO page links straight to the Search Console tab.
- Console, Permissions and Pricing Plans: every checkbox and field now has a label for screen readers, "Unlimited" is no longer cut off, and the page says how changes are saved (permissions save on tick, plans with Save Changes).
- Console, Pricing Plans: a plan that teams are on can no longer be deleted; the Delete button is disabled and the server refuses it, so paying teams are never moved to another plan by accident.
- Console, Projects: rows no longer pre-load every project page while you scroll, and long team and owner names are shortened so the usage and cost columns fit.
