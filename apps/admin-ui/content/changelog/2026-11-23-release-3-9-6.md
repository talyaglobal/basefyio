## What's new

- **The new-project dialog shows what you get.** For the organization you pick it lists the region, the compute (shared server, with no CPU or RAM reserved for your project alone), the database and file storage limits of the plan, what happens at a limit, and links to the full page. "Unlimited" only appears on plans that really have no cap.
- **A resources card on the project Overview.** It shows the connection host and port, region and location, compute, and database and file usage against the plan limit for this project and for the whole organization, with the time of the last measurement.
- **A plain answer on pricing.** Plans are flat monthly prices. Database and file storage are not billed per MB or per GB, and limits apply to the whole organization, not to each project. The new Pricing and limits page has a table for every plan, what is enforced at the limit today (projects, members, file uploads), what is counted and shown (database size, requests, traffic), and how often each figure is measured.
- A new dashboard-only route, `GET /api/projects/:id/resources`, backs the card.
