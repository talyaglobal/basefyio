## What's new

- **Bucket visibility can no longer be switched by accident.** Updating a bucket with a value such as `"yes"` used to make it public. `public` must now be `true` or `false`, both when you update a bucket and when you create one, and an update with no `public` field is refused instead of answering 200 and doing nothing.
- **Bucket names must be lowercase.** A name with capital letters used to be accepted, then stored in lowercase, which made the lowercase spelling fail as a duplicate. It is now refused with a message that says why.
- **Long table and column names are refused up front.** PostgreSQL cuts an identifier to 63 characters without saying so, so a longer table name was created under a shorter name than the one you typed. Creating a table or column with a name over 63 characters now returns a clear error.
- **JavaScript SDK storage calls do what they say.** `upload()` now applies the `contentType` option to a `Blob`, and `createSignedUrl(path, 600)` takes the lifetime in seconds. This ships with the next `basefyio-js` release.
- **Storage docs match the product.** A single upload request accepts files up to 500 MB (self-hosted installs can change this with `STORAGE_MAX_UPLOAD_MB`); `uploadResumable()` handles larger files. The Quickstart and SDK pages now show what `getPublicUrl()` and `createSignedUrl()` actually return.
