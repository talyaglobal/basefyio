## Security

- **Reset codes and sign-in links go to the right account only.** When no account had exactly the address entered, the lookup could fall back to another account whose address contained it (for example `bob@example.com` for `ob@example.com`). A password reset code or magic link requested for the shorter address was then issued for the other account. Lookups now match the full address, case-insensitively, and nothing else.
- Signing up with an address that is contained in another user's address is no longer refused as "already registered".
