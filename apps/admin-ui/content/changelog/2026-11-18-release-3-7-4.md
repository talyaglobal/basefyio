## What's new

- **The platform database is updated with versioned migrations.** The API no longer applies its schema with a command that could silently remove tables, columns or data on start. Each change is a reviewed migration, anything outside the platform schema is kept, and a failed migration stops the start instead of running on a half-applied schema.
- **API tokens work on project and team management routes.** Projects, database and policies, API keys, teams, integrations, blueprints, migrations, data import and embeddings accept a scoped token. A token needs the matching `:read` or `:write` scope, gets a 403 on a route it has no scope for, and only reaches the team it was created for.
- **Sensitive routes stay dashboard-only.** Creating or rolling tokens, sign-in and identity, ownership transfer and payments never accept a token; they answer 403 with the reason.
- A Turkish installation guide, `docs/KURULUM.md`, is linked from the self-hosting docs page.
- Every GitHub release now carries a `THIRD_PARTY_LICENSES.md` listing the npm runtime dependencies with their licenses and the container images the release is tested with.
