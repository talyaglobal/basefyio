## What's new

- A Turkish installation guide, `docs/KURULUM.md`, is linked from the self-hosting docs page.
- Every GitHub release now carries a `THIRD_PARTY_LICENSES.md` listing the npm runtime dependencies with their licenses and the container images the release is tested with.
