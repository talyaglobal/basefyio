## What's new

- **Profile pictures are stored as files.** A new profile picture is uploaded to storage, and your profile keeps only its address. Before, the picture itself was saved inside the profile as about 120 KB of text, and every page that loaded your profile downloaded it again. Pictures saved the old way move to storage the next time the profile is opened. They look the same.
- **The public health check shows less.** `GET /api/health` still reports the overall status, the platform version and one state per check (`ok`, `failing` or `skipped`). Error messages, timings, the server instance and the build are no longer public. When the platform database is down, `GET /api/health/ready` still answers 503, now without the database error text. Platform operators see the full report at `GET /api/health/details`.
