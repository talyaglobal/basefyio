## What's new

- **Secrets stay hidden until you ask for them.** Project pages and the project API no longer send the database password or the service key. Connect shows them masked, and Reveal fetches them on request. Each reveal is recorded in the audit log, and the response is never cached.
- **Who can reveal.** The organization owner, admins, and roles allowed to reset the database password.
- **The service key is shown only until it is first used.** After that, rotate it if you need a new one.
- **Update the CLI to 2.4.1.** `npm i -g basefyio-cli@latest`. Version 2.4.1 fetches the credentials through the new reveal route, so `basefyio link` and `basefyio status --show-keys` keep working, and it never writes a placeholder password into `.env`. Version 2.2.0 and older cannot read the hidden credentials.
