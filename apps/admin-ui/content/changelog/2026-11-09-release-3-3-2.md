## What's new

- **Adding a card:** the card form no longer shows a postal code field, so "Your postal code is incomplete" can no longer block saving a card.
- **Unpaid invoices:** an invoice that is open or unpaid now has a **Pay now** button that charges the card on file (or asks you to add one first). Paid invoices keep their Invoice and Receipt downloads.
- **Invoices list:** the empty message now explains that an invoice is created each time your plan is charged, and that Project costs is a running estimate, not an invoice.
- **One word for project status:** project cards in the grid, the project advisor and the admin disk page now say Deactivated instead of Paused.
