## What's new

- **Rotate the anon key.** Settings → API Keys now lists the anon key with Copy and Rotate. Rotating issues a new key at once and the old one is refused from the next request, so every app that ships the anon key needs the new value.
- **The environment block copies with its real values.** On Connect, Copy gives a working `.env` with the anon key, the service key and the database password filled in. On screen the service key and the password stay masked.
- The "Copy prompt" text for AI assistants keeps placeholders for the service key and the database password, because it is meant to be pasted into another tool.
