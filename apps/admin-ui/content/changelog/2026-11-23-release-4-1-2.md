## What's new

### Project logs

- **Search the whole history.** Search now covers every event, not just the page on screen. You can also filter by type (SQL, tables, auth, storage, flows, embeddings and more) and by date range, and refresh the list. A filter that matches nothing says so.
- **More is recorded.** Flows (created, changed, deleted, turned on or off, run), turning pgvector on or off, and changes to the embedding API key or provider now appear in the log. The key itself is never written to the log.
- **Accurate entries.** "Project updated" names only the fields that really changed. Events that arrive live show the person's name instead of an id. Logged SQL replaces quoted values with `'…'`, so data a statement writes is not stored in the log. Paging returns to the top of the list.

### Backups

- **Download any cloud backup** from Backup & Export. Encrypted backups are decrypted on the way out, so the file is a usable archive.
- **Delete exports you no longer need.** The owner, or a role allowed to delete projects, can delete a manual export. Nightly backups follow their 7-day retention and cannot be deleted.

### Auth

- **One password minimum.** Auth > Policies and Auth > Settings now show and change the same minimum length, and Keycloak and sign-up through the SDK both enforce it. Before, the two screens could disagree, for example 0 on one and 6 on the other.
- **Safer defaults for new projects.** New projects start with a 6-character minimum and brute-force protection: after 10 failed sign-ins the account is locked temporarily, for at most 15 minutes. Existing projects keep their settings. Both can be changed under Auth > Policies.
