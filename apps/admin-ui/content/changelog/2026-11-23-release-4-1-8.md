## What's new

- **A last warning before permanent deletion.** A deleted project stays in the trash for 24 hours. About six hours before it is removed for good, the person who created it and the organization's owners get a notification in the dashboard bell and an e-mail. Both link to the trash, where one click restores the project. Each person is told once per deletion. If you restore a project and delete it again later, you are warned again.
