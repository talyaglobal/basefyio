## What's new

- Project settings now send only the fields you changed, so saving from an out-of-date tab or while a teammate edits the same project no longer overwrites their folder, tags, name or description. Saving with no change says "Nothing to save".
- The dashboard and the password pages are served with `Cache-Control: private, no-cache` and `noindex`, and robots.txt now covers `/dashboard` itself, so signed-in pages stay out of shared caches and search results.
- Docs: new Quickstart and Backups & PITR pages, a Copy button on every code block, inline code without stray quote marks, and `/docs/embeddings` now opens the AI / Embeddings page.
- Website: pages share an Open Graph type and image and advertise the blog feed, long titles and descriptions are shortened for search results, `llms.txt` and `feed.xml` are in the sitemap, `/favicon.ico` and `/apple-touch-icon.png` exist, and the 404 page has navigation.
