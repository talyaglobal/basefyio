## What's new

- **Webhook flow ingress.** A flow with `trigger.type: "webhook"` is now callable from any external system at `POST /api/webhooks/flows/:flowId` using an HMAC-SHA256 signature — no API key required. The secret is returned once at creation time and can be rotated at any time with `POST .../rotate-webhook-secret`.
- **Sensitive header masking.** `Authorization`, `X-Api-Key` and similar header values stored in `http.request` actions are now masked as `***` in read responses. The raw value is never changed on disk; only the API response hides it.
