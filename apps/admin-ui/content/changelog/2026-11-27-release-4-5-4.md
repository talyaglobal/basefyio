## What's new

- Data Engine listings now reject a `limit`, `offset` or `cursor` that is not a whole number in range with a clear `400`. Before, `limit=abc` returned everything and `limit=0` returned one record.
- Listings accept the `cursor` returned as `nextCursor` by the previous page.
- Records with equal sort values now come back in a stable order, so paging no longer repeats or skips a record.
