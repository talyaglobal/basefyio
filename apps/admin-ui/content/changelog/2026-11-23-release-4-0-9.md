## What's new

- **One dialog for moving a project to trash.** The project Overview, the Projects list and project Settings now show the same dialog. It states the same retention (24 hours, restorable by the team owner until then) and what is lost after it. It asks for an optional reason and for the project name to be typed, and its button is red. Settings now asks for the reason too.
- **Clearer page structure for screen readers.** The dashboard has a single main region instead of one nested inside another. Every project page and the Projects page have a level-one heading, and the sidebars and the header navigation have names.
