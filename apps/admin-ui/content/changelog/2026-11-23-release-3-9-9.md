## What's new

- **Activating a deactivated project is safer.** Deactivating only closes sign-in; your users, roles and auth settings stay as they were, and activating opens it again. If sign-in cannot be re-enabled, the project now stays deactivated and tells you to try again, instead of showing as active with nobody able to log in. If a project's authentication realm is missing, it is recreated and the message says previous users could not be restored.
- **Clearer, harder-to-misclick dialogs.** Deactivating or moving a project to trash asks you to type its name, and the texts match what really happens (trash keeps a project for 24 hours; deactivated projects are not purged). Deleting an auth user asks for confirmation above the panel. Turning pgvector off asks first and says your stored embeddings are kept.
- **Auth password policy is validated.** Minimum length (6-128), history, expiry and brute-force fields show inline errors and cannot be saved out of range.
- **The Feedbacks page handles long threads.** Long text wraps, markdown renders (unsafe `javascript:` links are blocked), long posts collapse, pages load 25 at a time, and the counters follow your filters.
- **Friendlier errors.** A dropped connection now says "Can't reach the server" with a retry on the Database tabs, instead of an empty list or a raw "Failed to fetch". Screens no longer show server variable names.
- **Smaller and faster.** Team member lists no longer carry embedded avatar images, JSON and text responses are compressed, and the payment script loads only when you open the card dialog.
- **Search and filters.** Audit logs can be searched by actor e-mail or name and show the actor's real role. A nested field such as `meta.city` now matches in document collections, and the entity editor really removes deleted fields. A branch copy that skipped objects says which ones.
- **CLI:** `basefyio db vector status|enable|disable` and `basefyio db rotate-password` (basefyio CLI 2.4.0).
