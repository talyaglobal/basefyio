## What's new

- **Screen readers can name more buttons.** The mobile sort control and the "Created by me" toggle on Projects, the account menu in the header, and the Feedbacks page (status and type filters, show/hide deleted, attachment previews, and each comment's Reply, Edit and Delete and Remove file buttons) now carry labels, with pressed and expanded states where they act as toggles.
- Nothing changes visually.
