## What's new

- **A "What you get" note on the New project dialog.** It states the region (Nuremberg, Germany), that the database runs on shared infrastructure with no CPU or RAM reserved for the project alone, and that disk is not unlimited: database and file storage are billed per GB-month for what you use, with traffic and API requests metered.
