## What's new

- **A structured New project form.** Choose the organization (with its plan), connect GitHub, name the project, pick the compute size, set your own database password or generate one, see the region, and decide data access before the project exists. Free-plan limits are shown at the bottom.
- **Data access controls.** Turn the Data API on or off, choose whether new tables are exposed to the API automatically, and whether row-level security is switched on for every new table. The same three options live under Settings → Data access and can be changed at any time.
- **Dedicated compute sizes are shown honestly.** Shared compute is available now; dedicated sizes appear greyed out with the reason (plan or region capacity) until they are available.
- Existing projects keep working exactly as before: the Data API stays on, new tables are exposed as today and row-level security stays off unless you change it.
