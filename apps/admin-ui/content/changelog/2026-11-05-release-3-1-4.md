## What's new

- basefyio now runs an MCP server at `https://api.basefyio.com/api/mcp`. Claude Code, Cursor and other MCP clients connect with an API token.
- The token's permissions decide which tools the agent gets and what each call may do: list teams and projects, inspect tables, read and write rows, run SQL, browse storage and list auth users. Reads and writes each need their own permission.
- New permission `sql:read` runs read-only SQL. The database itself refuses any write, so an agent with it cannot change data or schema.
- **Connect an AI agent** on the API Tokens page starts a token with the MCP read-only preset, and the token page shows a copy-paste setup that reads the token from `BASEFYIO_MCP_TOKEN`.
- No MCP tool returns keys or passwords, deletes a project or rotates a key, and every call is recorded. A revoked token stops working on its next request.
- Setup and the full tool list: [docs.basefyio.com/mcp](https://docs.basefyio.com/mcp).
