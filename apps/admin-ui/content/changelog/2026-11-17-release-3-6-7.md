## What's new

- **Supabase import copies the whole schema.** When the importer could reach the source database, it asked for the server version in a way that always came back empty. It then reported an "unreadable server version" and rebuilt every table from its column types only, leaving out functions, views, triggers, foreign keys, row level security and policies, sequences, indexes and defaults. The version is now read correctly, so the schema is copied as it is on the source. Projects imported before this release should be imported again.
- **Errors raised in your functions reach the caller.** `raise exception 'Not enough coins'` inside a function used to answer a bare 500 "Internal server error". It now answers a 400 that carries your message, so a client can show it to the user.
