## What's new

- **Token lifetime is validated.** The auth settings API now rejects a token expiry outside 300 seconds to 30 days (negative, zero, tiny or huge values) with a 400, matching the dashboard field.
- **Editing a user no longer confirms their email.** Saving the Edit User form without changing the email leaves an unconfirmed (for example anonymous) user unconfirmed. A genuinely new address is still confirmed as before.
