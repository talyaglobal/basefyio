## What's new

- REST API Explorer: filter and sort examples use the selected table's real columns, and the update and delete examples filter on its primary key with a value of the right type (a uuid key no longer gets `id=eq.1`).
- REST API Explorer: each endpoint lists its response shape and has a Copy as fetch (JS) button next to Copy as curl; a note points to the collections routes.
- Project overview: the Database, Auth Realm and Anon Key cards have copy buttons.
- Database: the Create index dialog has an optional name; the Create trigger dialog lists the project's trigger functions and offers FOR EACH ROW or FOR EACH STATEMENT.

## What's fixed

- REST API Explorer: the selected table and the endpoint URLs always agree; the page used to show URLs for a table the dropdown did not list.
- Project overview: the Move to Team button and the header user name no longer shift the layout when they load.
- Database: the index delete button stays visible without scrolling sideways and the Size column no longer wraps.
- Database: turning off an extension asks "Disable", not "Delete".
- Dialogs without a description no longer log an accessibility warning in the browser console.
