## What's new

- The sign-up form now includes a Cloudflare Turnstile human check, which stops automated mass sign-ups. The check is invisible for most people and only asks for a click when it is unsure.
- If Cloudflare cannot be reached, sign-up still works; the per-IP rate limit keeps applying.
- Self-hosting: set `TURNSTILE_SITE_KEY` and `TURNSTILE_SECRET_KEY` to switch it on. Without them nothing changes.
- The comparison pages on the website cite each competitor's official documentation.
