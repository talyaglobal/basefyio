## What's new

- `POST /auth/signin` with a missing or malformed body now answers `400` ("email and password are required") instead of `500` (feedback #252).
- Anonymous users in Auth > Users: the detail panel shows an Anonymous provider, no longer offers Send recovery, Send verify, Set password or Require MFA (they have no real e-mail), and the users list has an "Anonymous only" filter (feedback #253).
