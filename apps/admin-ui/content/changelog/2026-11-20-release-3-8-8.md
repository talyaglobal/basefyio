## What's new

- The SQL editor and `sql/execute` return `RAISE NOTICE` / `WARNING` messages, and a SQL error now reports the line and column Postgres pointed at (feedback #265).
- REST reads state their 1,000-row ceiling (`X-Max-Rows`), and `?page=N` answers a `400` that points at `limit` and `offset` instead of failing (feedback #266).
- Database > Functions shows whether each function is `SECURITY DEFINER` or invoker; generated columns are read-only in the data editor; enum columns show their type name instead of `USER-DEFINED` (feedback #267).
