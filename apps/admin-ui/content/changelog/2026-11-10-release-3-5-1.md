## What's new

- Adding media to a feedback comment or a new feedback now checks the files straight away: only images and videos, at most 5 files, images up to 5 MB and videos up to 20 MB. A rejected file is named in the message.
- A failed send no longer uploads the same files again on retry, and the button shows which file is uploading.
- Feedback search treats Turkish İ, ı, I and i alike, and ignores accents.
- A feedback description can no longer be saved empty.
- A deleted feedback can no longer change status or be edited, and it is left out of the counts and the total. A "Show deleted" filter lists it when needed.
