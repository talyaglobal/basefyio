## What's new

- **Admin console, infrastructure costs:** the allocated cost is now each project's share of the real server bill (never above it), with the full-tier estimate shown beside it, so the figures add up to what the host costs.
- **Admin console, overview:** the paying teams count now also tells how many of them are past due.
