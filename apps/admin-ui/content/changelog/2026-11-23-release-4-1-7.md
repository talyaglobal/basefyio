## What's new

- **A standby copy of the platform database, watched every five minutes.** The platform's PostgreSQL server streams every change to a second server in the same region. If the standby disconnects, falls behind, or risks losing WAL it has not replayed, the operations team gets a critical alert after two failed checks.
- **Every push is scanned for secrets.** CI runs gitleaks over the whole history on each push. A leaked key fails the build.
- **Repeatable website builds.** The website image now installs the exact versions in its lockfile.
- **Where NULLs sort, documented.** The REST API docs explain the default NULL order in each dialect. They also show how `.nullsfirst` and `.nullslast` give the same order from basefyio-js and from supabase-js.
