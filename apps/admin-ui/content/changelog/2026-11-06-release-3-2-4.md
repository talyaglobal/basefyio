## What's new

- Escape closes the project and team switchers, the Docs and user menus, the bulk Add tag and Move to folder menus, the Move to Team dialog and the Auth user panel.
- The project switcher focuses its search box when it opens and moves through the list with the arrow keys; Enter in the search box opens the first match. The team switcher, Docs and user menus take the arrow keys too.
- Switching project keeps you on the same section (for example Connect) instead of returning to Overview.
- Unknown pages show a branded not-found page with links back to the dashboard and your projects.

## What's fixed

- A missing project, or one you cannot access, shows "Project not found" instead of a generic "Failed to load project" toast and a redirect; a temporary failure offers Try again.
- Overview search clears and closes on Escape and shows a single clear button.
- Identical requests started together on page load (profile, teams, changelog, lists) are sent once, and the project sidebar no longer prefetches every section in the background.
