## What's new

- **Extra database users.** Open any project's Connection page and click "Add database user". Give it a label, optionally grant membership in `anon`, `authenticated`, or `service_role`, then copy the ready-made pooler URI. Each role gets a strong random password stored encrypted at rest; you can rotate it or delete the role at any time. Up to 10 extra roles per project.
- **CLI `bf link` now lists projects newest-first**, making it faster to find a recently created project.
- **Migration counter fix.** Projects with more than 100 migrations no longer under-count applied migrations, re-run already-applied files, or record them non-atomically.
