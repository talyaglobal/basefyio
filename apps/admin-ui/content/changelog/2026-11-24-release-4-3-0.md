## Fixed

- **The user form checks what you type.** Under **Auth → Users**, adding or editing a user now refuses an e-mail without a domain suffix, such as `name@example`, and a phone number that is not in international format. Numbers like `+90 555 123 45 67` are stored as `+905551234567`, and an empty field clears the number. Passwords must reach the project's minimum length, and names can be at most 100 characters. The same checks apply when you call the admin API, so a script gets the same answer as the form.
- **MFA state in the user panel.** A user's panel now says whether MFA is set up, required, or neither. A **Require MFA enrollment** request can be taken back with **Remove MFA requirement**. Before, it could only be set.
- Empty first and last names are still filled in from the e-mail address, because the sign-in needs them.
