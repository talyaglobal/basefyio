## What's new

- **Both Redis instances require authentication.** The cache and the job queue no longer accept connections without the password, which closes an internal-network exposure of queues, rate limits and usage counters.
- Existing data and queued jobs are kept; the API reconnects on its own.
- Self-hosted installs generate the passwords during upgrade.
