## What's new

- Data editor: rename a table from its menu in the sidebar.
- Data editor: export the table (or the filtered rows) as CSV or JSON.
- Data editor: the Create table dialog and the column panel now have a Unique option; the column list shows which columns are unique.
- Data editor: the table name is checked as you type (already taken, reserved SQL word, invalid characters), and empty-name messages are in English.
- Data editor: Clean duplicates starts from "every column except the primary key", so the preview is no longer always 0, and the result stays visible under the column list.
- Data editor: searching column types ranks the best name match first, so typing "bool" and pressing Enter picks Boolean.

## What's fixed

- Data editor: adding a column on page 2 no longer renumbers the rows from 1; the row numbers always match the page shown.
- Data editor: renaming a column reports the new name; "1 row" is no longer "1 rows".
- Data editor: an empty NOT NULL column or text in a number column is reported before saving, naming the column.
- Data editor: a JSON collection's count in the sidebar updates after you add a document, the All / SQL / JSON counts follow the search box, and a collection's backing table no longer shows up as a SQL table.
- SQL editor: two browser tabs on the same project no longer overwrite each other's queries.
- SQL editor: the total stays visible on page 2 and later pages, a query that writes inside a WITH runs once instead of once per page, closing a tab that holds a query asks first, and the tab bar and result table no longer get clipped.
