## What's new

- Upsert defaults to the id conflict target and uses DO NOTHING when nothing is left to update; signUp rejects empty credentials with 400
- Data engine: plain-object filters (`{"grp":"g1"}`) and the SDK sort format now work instead of returning 503; malformed filter or sort returns 400.
- Data engine: writes are validated against the entity fields (required fields, scalar types), array bodies are rejected, documents over 1 MB return 413, and array and nesting limits are enforced.
- `basefyio-js` 2.3.1: README, `sideEffects`, `engines`, `VERSION` export, and no source maps in the package.
