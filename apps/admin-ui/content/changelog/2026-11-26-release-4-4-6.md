## What's new

- **Encrypted-only database connections (optional).** `PGBOUNCER_CLIENT_TLS_MODE=require` makes the connection pooler refuse unencrypted client connections. The default stays `allow`, so existing connections keep working.
- **Several API replicas, one pooler configuration (optional).** `PGBOUNCER_RECONCILE_SECONDS` (for example `60`) makes every API replica rebuild its pooler configuration from the database on a timer and reload it only when something changed, so a project created on one replica is known to the poolers of the others. Off by default.
