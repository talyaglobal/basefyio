## What's new

- **Updates no longer take the platform offline.** Until now, each update stopped the running API, dashboard and website before the new ones were ready. For a short time, the dashboard could show "404 page not found" and API calls could fail. Now the new version starts beside the old one, takes over as soon as it answers, and only then does the old one stop. If the new version does not start, the old one keeps serving.
- **What stays the same.** Your data, sessions and API keys are untouched. Realtime connections reconnect on their own when the old version stops.
