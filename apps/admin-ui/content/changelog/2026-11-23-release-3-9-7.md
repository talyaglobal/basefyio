## What's new

- **The Pricing and limits page now matches the plans you can buy.** The table showed a fresh installation's starting values instead of the hosted plans. It now lists Free, Pro ($20) and Business ($100) with their real project, database, file storage, member, egress, request and monthly-active-user limits. The Billing page and `GET /api/billing/plans` remain the source of truth.
