## What's fixed

- **Tables outside `public` open with their schema every time.** Since v4.0.6 they were listed as `schema.name`, but the table the editor opened first, the tabs it restored and the row counts still used the bare name. A project whose first table was outside `public`, such as `auth.users`, could open it empty. The editor now opens a public table first and keeps the schema everywhere.
- **A table list that fails to load says so.** If the list cannot be loaded, for example while you are offline, the sidebar now says so and offers Try again instead of "No items of this type yet". It reloads by itself when your connection comes back.
