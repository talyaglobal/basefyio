## What's fixed

- **GitHub connection check.** The team GitHub status now asks GitHub whether the stored token still works. An expired token shows as "Expired" with a **Reconnect with GitHub** button on the team page, and the project Integrations page explains it and links straight to the team Integrations section instead of showing a green "connected" box with no way forward. A repository list that fails to load now shows its error in the card.
- **Manage button.** On the project Integrations page it opens the team page scrolled to Integrations.
- **AI assistant history.** The first conversation of a new account is now saved on the server, so it survives a page reload instead of failing silently. Closing a chat tab asks for confirmation first.
- **AI assistant context.** A project you have open is recognised even when it belongs to another of your teams, and the assistant no longer asks you to open a project that is already open. "What can basefyio do?" now covers the whole platform, not only PostgreSQL.
- **Chat layout.** Your latest prompt no longer sticks over the reply text while you scroll.
