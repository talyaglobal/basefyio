## What's new

- **PgBouncer and MinIO run from pinned image digests.** An upstream release can no longer change what runs in production by itself; upgrades are a reviewed change in git. The pinned images are the ones already running, so behaviour is unchanged. Connections through the pooler reconnect once during the switch.
- **Automated update proposals for the database image.** Digest updates are proposed as pull requests and are never merged automatically.
- A rehearsal environment for database replication and failover is part of the repository for operators who run their own stack.
