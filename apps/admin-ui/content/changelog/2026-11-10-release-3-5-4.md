## What's new

- Switches: an off switch now has a clearly visible track in dark and light mode, so you can tell which options are on.
- Dark mode contrast: feedback status badges, red text (Delete Forever, Danger zone, Sign out), Trash captions, the sidebar version, NULL cells and primary buttons now meet readable contrast.
- Theme toggle: it now cycles Light, Dark and System (follows your operating system) and says which one is active.
- Admin console: the sidebar has the same theme toggle, so the console follows your choice too. The preference is stored per site, so set it once on admin.basefyio.com as well.
