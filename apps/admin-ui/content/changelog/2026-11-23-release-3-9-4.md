## What's new

- **Deleting a non-empty bucket needs `force=true`.** `DELETE /api/projects/:id/storage/buckets/:name` now answers `409` with the object count when the bucket still holds files, and changes nothing. Pass `?force=true` to delete the bucket and everything in it. The dashboard and the CLI already ask for confirmation and send it for you. The MCP `delete_bucket` tool takes an optional `force` argument, and the SDK has `deleteBucket(name, { force })` (basefyio-js 2.4.0).
- **Bad REST input answers 4xx without internal details.** Out-of-range values, malformed statements and constraint conflicts return a short `400` or `409` message that names no table or column; real server faults stay a generic `500`. Storage reads of a missing bucket answer `404`, and `DELETE objects` with an empty list or a `..` path answers `400`.
- **Creating a folder twice no longer happens.** Double-clicking Create folder makes one folder, and a name that already exists in the organization answers `409`. Existing duplicates are left as they are.
- **The internal `_bf_ctid` column is hidden in the Data editor.** Editing and deleting rows in tables without a primary key keeps working.
