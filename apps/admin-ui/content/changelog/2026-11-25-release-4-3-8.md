## What's new

- **Advisors.** Open **Advisors** in a project's sidebar to scan its database. Findings are grouped into security and performance, each with a severity and a ready-to-copy fix:
  - tables with row level security off (an error when `anon` or `authenticated` can write to them),
  - tables with row level security on but no policy,
  - `SECURITY DEFINER` functions without a pinned `search_path`,
  - foreign keys without a covering index,
  - indexes that have never been used,
  - tables without a primary key.
- **Read-only.** The scan only reads the database catalogs, inside a read-only transaction, with a time limit per check. Fixes are shown, never applied: you choose what to run.
- **API.** `GET /api/projects/:id/advisors` returns the same report (optional `category` filter); it is documented in the project admin API reference.
