## What's new

- **Progress for every upload.** Files under 64 MB used to show only "Uploading…". Every upload in Storage now shows its percentage.
- **Cancel an upload.** Cancel upload stops the current file and the ones after it, and tells you how many were already uploaded. A cancelled large upload frees its server-side upload session right away.
- **List open upload sessions.** `GET /api/projects/:projectId/storage/buckets/:bucketName/upload-sessions` returns the resumable uploads you can continue. The service key and the dashboard see all of them, and a signed-in user sees their own.
