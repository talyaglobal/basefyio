## What's new

- The status page's own realtime check asked for a channel name that v3.5.0 now refuses, so it reported "Realtime is down" and e-mailed an alert although realtime was working for every project. The check now subscribes to `table:slo_probe` and the incident closes itself.
- Nothing changes for apps: streams with valid channels behave exactly as in v3.5.0.
