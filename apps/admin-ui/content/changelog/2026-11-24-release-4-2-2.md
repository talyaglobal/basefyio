## What's new

- **Sign-out ends the session on the server.** The new `POST /api/rest/v1/auth/signout` route revokes a user's refresh token, so it can no longer be used to get new tokens. It can also end every other session of the user (`scope: "others"`) or all of them (`scope: "global"`). In basefyio-js 2.5.0, `signOut()` calls this route. Until now, sign-out only cleared the session in the browser.
- **Clearer answers when nobody is signed in.** In basefyio-js 2.5.0, `getUser()` returns a 401 error without sending a request. `GET /api/rest/v1/auth/me` without a token answers 401 instead of 403. Calling `signOut()` with no session does nothing and fires no `SIGNED_OUT` event.
- **Folders in storage listings.** A folder entry now carries only `prefix`, as the docs describe, instead of an empty `name`.
- **Who may write with the anon key.** The SDK reference now explains it: the anon key alone can read, and writes need a signed-in user, row-level security policies or the service key.
