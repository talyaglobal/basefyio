## What's new

- Import from ZIP: an archive without manifest.json, project.json or database/dump.sql (or a file that is not a ZIP) is refused with a clear message instead of creating an empty project, and import warnings are shown in the confirmation.
- Import from ZIP, Override an existing project: you must type the target project's name before the import can start, and the server refuses the request without it, so a wrong click can no longer overwrite another project's data.
- Docs: new pages for Flows, AI / Embeddings, Integrations and Branches, listed in the docs menu and search.
