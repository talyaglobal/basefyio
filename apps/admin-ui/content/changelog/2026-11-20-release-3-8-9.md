## What's new

- Creating a trigger on a function that does not exist (or any other rejected index, trigger or function definition) now answers `400` with the database's reason instead of "Internal server error" (feedback #269).
- An unknown filter operator in a REST query (`?id=zz.1`) is answered `400` with `Unknown operator`, now covered by a test (feedback #268).
