## What's new

- **Audit logs:** pages load much faster, the page you are on no longer shifts while new records arrive, and the Last button always lands on the last page.
- **Audit logs:** a From date after the To date now says so instead of showing an empty result, and the list shows Loading while it fetches.
- **Users search:** `%` and `_` are searched as plain text instead of matching every user.
- **Admin console:** the signed-in count now includes Google and token-refresh sign-ins, and a plan period that has ended shows as Lapsed in the plan list.
