## What's new

- **The API no longer holds the Docker socket.** It talks to Docker through a restricted proxy on a private network that only the API can reach; image builds, plugins, swarm, secrets and registry credentials are not reachable from it.
- **Internal credentials are explicit.** The message bus and Redis connections read dedicated variables, and an installation that lacks them stops at start-up with a clear message instead of falling back to a published default.
- **More reliable dedicated databases.** A temporary error from Docker is no longer mistaken for a missing container, and the API waits for Docker at boot instead of disabling the feature.
- Self-hosted installs upgrade without action: the installer generates the new values. Hosts that cannot run the proxy can opt out with `deploy/compose/docker-socket-direct.yml`.
