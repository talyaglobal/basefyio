## What's new

- **Bucket ownership is enforced on every storage request.** A bucket name that could be spelled the same way by two projects can no longer be reached by the wrong one: reading, listing, uploading, moving, copying, signing and deleting all check who owns the bucket, and answer "Bucket not found" otherwise. Existing buckets keep working for their projects.
- **New projects get a collision-free storage namespace.**
- **S3 access keys, bucket tools and CLI commands (preview, off by default).** Projects will be able to create project-scoped S3 keys for standard S3 clients, create and delete buckets through the MCP tools, and manage them with `basefyio storage`. Nothing is enabled until an operator turns it on.
