## What's new

- **Search users.** Authentication → Users has a search box that finds users by e-mail, username, first or last name across the whole project, not only the rows on screen.
- **Every user is reachable.** The list used to show the first 100 users of a project and no more; it now loads 100 at a time with **Load more**. The API takes `?search=`, `?first=` and `?max=` on `GET /projects/:id/auth/users`.

## Fixes

- Exports and nightly backups of a project with more than 100 users contained only the first 100; they contain every user now.
- After a Supabase import, the result dialog cut off its table, and could say "Every counted table matches the source" while warning that hundreds of tables were imported empty. It is wider now, and tables that were only counted as empty through the source's API are named as unverified, with how to count them directly.
- Calling a database function with `POST /rest/v1/rpc/<function>` answers 200 (it answered 201). A function that changes data, called with GET, answers 405 with the reason instead of 500. The Functions page shows the full URL, and the SDK and API docs describe `rpc`.
