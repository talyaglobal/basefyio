## What's new

- Import Data: when a job ends the dialog shows rows read, inserted, updated, skipped and rejected, and an "Error report" button downloads a CSV with the row number, the reason and the raw row of every rejected line.
- Import Data > Create new: underscores can be typed in the table name; the name is tidied up when you leave the field, not on every keystroke.
- Import Data > Create new with Skip or Update: the chosen conflict columns become a unique constraint on the new table, and a table left half-made by a failed import is removed. New tables now default to a plain insert.
- Import Data also reads UTF-16 and Windows-1254 files (with an encoding selector), JSON and NDJSON, decimal commas and dd.mm.yyyy dates, and warns about header-only files and columns that were not matched.
- The import progress stream and the job routes now use the Authorization header instead of a token in the URL, and check that the job belongs to the project.
