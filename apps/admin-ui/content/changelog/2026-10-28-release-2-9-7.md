## What changed

- Routine disk cleanup on the server could remove the name of an image that a running service still uses. The next release then tried to download that image again and stopped when the download was refused, as happened with the v2.9.6 release. Names like these are now restored after every cleanup and before every release. The image and the running service stay exactly the same, so nothing restarts.
