## What's new

- **Cleaner API restarts.** When a new API instance starts, it now waits for the database to become reachable before it applies pending migrations, instead of failing once and restarting. Deploys and scale-ups bring new instances into service without that first failed start. For self-hosted installations the wait is 60 seconds by default and can be changed with `MIGRATE_CONNECT_TIMEOUT_MS`.
