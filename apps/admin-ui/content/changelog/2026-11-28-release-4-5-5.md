## What's new

- **TLS notice on the project page.** basefyio now runs on new infrastructure, and database connections to `db.basefyio.com:6432` have to be encrypted. If an app of your project still connects without TLS, a notice appears at the top of the project page with the one-line fix. It disappears by itself as soon as a TLS connection from the project is seen.
- **Connection guide updated.** The connection examples in the documentation now end in `?sslmode=require`. Host, port, user name, password and database name do not change.
- **No action needed** if your apps already connect with TLS.
