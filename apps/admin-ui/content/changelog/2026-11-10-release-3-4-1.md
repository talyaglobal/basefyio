## What's new

- Console, Audit Logs and Root Alerts: actions and alert kinds read as words ("Auth role updated to root"), project-key actors show the project name instead of an id, team and project targets are named, and the empty "JsonNull" metadata and "HTTP: - -" lines are gone.
- Console, Project Deletion Reasons: the Time column no longer clips, raw ids are replaced by a short project id, each record shows whether the project is in the 24-hour trash or permanently deleted, and the Overview says that its deleted count is the trash only.
- Console: sizes use one unit scale everywhere (8.95 GB, 2.42 KB, 0 B), months read "Oct 2026", Search Console and Sitemaps dates use the standard format, hour totals have thousands separators, and the audit date filters are labelled.
- Console tables: Margin, Reset Password and rate lines no longer clip, the rate editor fields stay inside their box, Users, Costs and Storage show a message when a search finds nothing, Storage can be searched and loads 50 buckets at a time, and Organizations can be searched and sorted.
