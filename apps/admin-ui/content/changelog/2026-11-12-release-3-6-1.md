## What's new

- Switches, checkboxes, drop-downs and icon buttons now carry accessible names, so a screen reader announces which permission, row, status or setting each one controls. This covers the API token permission switches, table row checkboxes and delete buttons, select-all on Projects, the status picker on Feedbacks, the billing address fields, the account notification toggles, and the Settings and Connect drop-downs.
- Closing a dialog with Escape or Cancel returns keyboard focus to the button that opened it instead of dropping it to the top of the page.
- The per-project cost rows on Billing have a real expand button with its state announced, so the cost breakdown opens from the keyboard.
