## What's new

- The pricing section on basefyio.com now shows each plan's monthly active users and a Usage rates table (compute per hour, storage, egress and API requests), matching the Billing page. `/pricing` opens it.
- The marketing site, docs and blog describe basefyio as a hosted backend with a SQL database; two blog posts moved to shorter addresses and the old links redirect.
- Sign-in, sign-up and password forms now tell password managers which field is which, show the password rules under the field, let you reach the show/hide button with the keyboard, and open the dashboard if you are already signed in.
- The sign-in subtitle now reads "Sign in to your account", and the app title no longer says open source.
