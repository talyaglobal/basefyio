## What's new

- `getPublicUrl()` in `basefyio-js` now returns a link that carries the project's public key, so it opens directly in an `<img>` tag or a browser link. Before, the link answered 401 unless you added the `apikey` header yourself.
- The API accepts the public (anon) key in the query string on routes that allow it. The service key is still refused there.
- `basefyio-js` 2.7.1 contains the SDK side of this change.
