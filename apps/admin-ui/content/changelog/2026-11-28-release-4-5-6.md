## What's new

- **New infrastructure.** The hosted platform now runs on a larger cluster. Your project addresses, API keys, database user names and passwords, storage files and sign-ins did not change.
- **Database connections need TLS.** Connections to `db.basefyio.com:6432` must be encrypted. If your app connects without TLS, add `sslmode=require` to the connection string; the project page shows a notice until a TLS connection is seen. See the Connect guide in the documentation.
- **Point-in-time recovery is paused on the hosted platform for now.** Restoring a project to an exact second from the dashboard is not available while we rebuild it on the new platform, and the panel refuses new restores. Nightly backups of active projects continue. If you need to recover data, write to support@basefyio.com and we will help you right away.
- **Documentation updated.** The Backups page and the operations notes say what applies to the hosted platform and what applies to self-hosted installations, which are not affected.
