## What's new

- The Auth and Data Engine docs now show the real endpoint paths (`/api/rest/v1/auth/...` and `/api/v1/projects/:projectId`), and the architecture overview matches.
- The Auth docs no longer suggest sending the key as a query parameter; use the `apikey` header so keys stay out of logs and referrers.
- The self-hosting page, a blog post and the SDK, CLI and geo package metadata now link to the current repository.
