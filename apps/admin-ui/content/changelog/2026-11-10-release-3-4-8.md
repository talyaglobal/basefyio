## What's new

- Sheet to App: CSV files are decoded as UTF-8 (or UTF-16 / Windows-1254 when the file is saved that way), so Turkish letters are no longer garbled and column names become `musteri_adi`, `sehir`. The table takes the CSV file's name.
- Numbers like `12,50` and dates like `01.02.2026` are read in the file's own format: they become `numeric` and `date` columns with the right values. Excel date cells arrive as dates, not serial numbers.
- A source column called `id`, `created_at` or `updated_at` is no longer dropped: it is kept as `source_id`, `source_created_at`, `source_updated_at`, and the draft shows a warning.
- The draft can be edited before you approve it: click Edit to rename tables and columns, change types and set nullable, then Save changes.
