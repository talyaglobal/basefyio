## What changed

- The dashboard is being simplified in small steps behind a switch (`nav_v2`). Nothing changes for you yet: the switch is off, and when it comes on it can be tried by a few accounts first.
- Every dashboard page and the critical flows — sign-in, the projects list, a project's overview, the table editor, a SQL statement, the REST explorer, storage, auth, backups and connection details — are now exercised by an automated browser on every change, so a page that moves behind a redirect cannot quietly break.
- `GET /api/features/me` returns the feature switches as the signed-in user sees them.
