## Fixed

- **One-time codes are tied to the user's address.** Password reset, e-mail verification and magic-link codes can now be sent together with the e-mail address. The code then works only for that address, and after five wrong codes the user must request a new one. Until now, a code alone was enough, and there was no limit on wrong guesses.
- **Older apps keep working.** Apps that send only the code still work. After 20 wrong codes in an hour, though, that path closes for the project, while requests that include the address keep working.
- **basefyio-js 2.6.0** sends the address when you pass it: `resetPassword(code, newPassword, { email })`, `verifyEmail(code, { email })` and `verifyMagicLink(code, { email })`. We recommend updating.
