## What's new

- **Data editor search works on every table.** Filtering rows in a table that has a uuid column used to fail with an error. Search now covers uuid columns too.
- **Stable pages in the data editor.** Without a sort, large tables could show the same row on two pages and skip another. Pages now follow the primary key (or the physical row order for tables without one), and a sort you choose keeps the primary key as its tie-breaker.
- **The audit log records what really happened.** A failed request, such as a rejected change or a missing resource, was stored with a success code (200 or 201). It is now stored with its real status, for example 403, 404 or 500.
- **Safer writes in the JavaScript SDK.** `update()` and `delete()` without a filter now stop before anything is sent, so a missing `.eq()` can no longer change or remove a whole table. `single()` expects exactly one row and `maybeSingle()` at most one; more than one is an error. To change every row on purpose, use `bf.sql()`. This ships with the next `basefyio-js` release.
