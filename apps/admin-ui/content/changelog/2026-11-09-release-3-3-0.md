## What's new

- Account: the first name can no longer be saved empty, in the form or through the API.
- New Project: pick the team the project is created in (it no longer lands in the active team without saying so), see the project name rules, and choose the project to overwrite explicitly when importing a ZIP.
- Import from Supabase: an invalid project URL now shows an inline error, the Validate button says what is missing, and the show/hide button on the key field has an accessible name.
- Projects: every card and list row has a visible "..." actions button, the search box has a clear button and clears with Esc, Clear all also resets the folder filter, an empty folder or tag name explains itself, and long lists load 60 projects at a time.
- Overview: the "Created this month" trend no longer claims growth for zero projects, "1 owner / 2 owners" is pluralised, and the cards and quick actions are real links you can open in a new tab.
- Feedback: a blocked screen capture explains itself, Esc or Cancel asks before discarding a typed draft, and the page address can be corrected.
- Dashboard: each section has its own browser tab title, a "Skip to content" link, a consistent keyboard focus ring, labelled icon buttons, and a readable logo in dark mode. The empty notification panel disables Mark all read and Clear.
- Release notes: wrapped list items and bold text spanning two lines render correctly, each note links to the newer and older one, and the Project costs note no longer claims API requests are billed.
