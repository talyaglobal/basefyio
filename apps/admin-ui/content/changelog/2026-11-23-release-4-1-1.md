## What's new

- **SQL editor changes reach the Data editor.** A statement that can change rows or the schema, such as `UPDATE` or `DROP TABLE`, now refreshes every open Data editor for the project, in any tab. If the table you have open was dropped or renamed elsewhere, the editor says so instead of quietly opening another table.
- **Query results stay out of browser storage.** The Data Engine query editor keeps your queries between visits but no longer stores their result rows in the browser. The SQL editor already did not.
- **Entities show their document count** in the Data sidebar, like tables and collections.
- **Accessibility.** Unlabelled table columns (actions) now have names, and the code samples on Connect can be reached with the keyboard. Inline links are underlined, not only coloured, and the header avatar no longer repeats your name. The Account page has section headings, and the REST explorer and Integrations no longer skip heading levels.
