## What's new

- Docs on phones: long inline code (URLs, paths, headers) now wraps instead of pushing the page wider than the screen.
- Light theme: inline code in the docs, the copy-code button and the "Beta" badge on the home page now meet the 4.5:1 contrast minimum.
- Home page: the API example card no longer overflows on narrow screens.
