## What's new

- Restore Backup: the dialog opens on "Restore as new project"; overwriting the current project requires typing its name.
- Point-in-time recovery: a time outside the recovery window is flagged before you recover, the picker includes seconds and the confirmation shows your time zone; the empty state explains that base backups run nightly.
- Import from ZIP: the file picker refuses files that are not .zip.
