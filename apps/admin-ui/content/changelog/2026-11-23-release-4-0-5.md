## What's new

- **Two-factor authentication is your choice.** Turn on an authenticator app for your own account under Account, and sign-in asks for the code after your password. You can turn it off again there at any time.
- **Organizations cannot make it mandatory.** An organization can no longer require two-factor authentication for its members, and no sign-in (password, Google, GitHub or the CLI) sends anyone to set it up.
