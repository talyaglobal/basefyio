## What's new

- A multi-statement SQL script (or any statement that cannot be paged) now returns at most 1,000 rows per result set. The response carries `capped: true` when rows were cut, so a large result can no longer freeze the editor.
- The SQL editor keeps only your queries in browser storage, never result rows, so large results no longer overflow storage and table data does not stay on disk.
