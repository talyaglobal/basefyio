## What's new

- Billing: when you are not the team owner, Billing Details, Add or Update Payment Method and the student discount form are read-only, with a note saying who can change them (before, they looked usable and then failed with an error).
- Billing: the Country field is now a list of countries.
- Billing: the cost table is labelled Usage value so far and Projected usage value, and on the Free plan it says these amounts are not charged to you.
- Billing: switching team clears the student email, code and any message from the previous team, and an invalid email is caught before anything is sent.
- API tokens: the error message no longer stays on screen over the Create and Cancel buttons; it is replaced or removed as soon as you fix the problem. The expiry date cannot be in the past, with a clear message if it is.
