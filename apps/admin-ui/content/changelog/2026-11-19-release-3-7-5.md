## What's new

- **Downloads from a public bucket are cache-friendly.** The download route sends `ETag` and `Last-Modified`, answers `304 Not Modified` to a matching `If-None-Match`, and marks the file `Cache-Control: public, max-age=300, stale-while-revalidate=60`, so a CDN or browser can keep a copy.
- **Protected files are never shared-cached.** A private bucket, or a path covered by an access rule, answers `Cache-Control: private, no-cache`, so a CDN placed in front cannot hand a protected file to someone else.
- Self-hosters can change the lifetime with `STORAGE_PUBLIC_CACHE_SECONDS` (`0` revalidates on every read).
