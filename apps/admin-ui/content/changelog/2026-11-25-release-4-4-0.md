## What's new

- **Signed release images.** The `basefyio-api`, `basefyio-ui` and `basefyio-website` images of each release are signed with cosign (keyless: the signature names the release workflow as the signer), so you can check that an image you pull or deploy came from this repository's build.
- **Software bill of materials.** Each image carries an SPDX SBOM as a signed attestation, listing every package inside it; the SBOMs are also kept as downloadable files for 90 days.
- **How to verify.** The new guide `docs/guides/verify-images.md` has the two commands: `cosign verify` for the signature and `cosign verify-attestation` for the SBOM.
- Signing happens after the deploy and never delays or blocks a release.
